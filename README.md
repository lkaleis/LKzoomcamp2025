# 🚀 Data Engineering Zoomcamp Course - My Learning Journey  

## 📌 About This Repository  
This repository contains my work and notes as I follow along with the **[Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp)** course.  
It will cover: containerization and infrastructure as code, workflow orchestration, data ingestion, data warehousing, analytics engineering, and batch & streaming processing. The course culminates in an open source project in which I will find an open data set to work on, leveraging all of the skills learned in this course to produce a final dashboard visualizing insights from the data.
